B. DateWindowSampler
--------------------
Purpose: Sample valid date sequences for training

Input:  window_start=2018-10-23, window_end=2019-10-23
Output: sequence_dates = [2019-03-13, 2019-03-14, ..., 2019-07-23]  # 92 dates
        available_tickers = ['AAPL', 'MSFT', ...]

Key constraint:
  - Anchor date (last date) must have SEQ_LEN-1 dates before it
  - First valid anchor = stock_data_start + SEQ_LEN


C. ParquetFilteredReader
------------------------
Purpose: Read ONLY the rows needed from parquet files

extract_ticker_data(tickers=['AAPL', 'MSFT'], dates=[92 dates], ...)

1. Group tickers by batch_idx:
   batch_0 -> ['AAPL', 'MSFT']
   batch_1 -> ['GOOGL']

2. For each batch, read with PREDICATE PUSHDOWN:
   pd.read_parquet(
       'batch_0.parquet',
       columns=['date', 'ticker', ...features..., 'target_ret_1d'],
       filters=[
           ('ticker', 'in', ['AAPL', 'MSFT']),
           ('date', '>=', min_date),
           ('date', '<=', max_date + 1 day)  # +1 for timezone offset
       ]
   )

3. Return: {'AAPL': DataFrame(92 rows), 'MSFT': DataFrame(92 rows), ...}


D. ConditionalFactorDatasetV2
-----------------------------
Purpose: Prepare tensors for model with masking

Input:
  - tickers: ['AAPL', 'MSFT', ...]  (32 tickers)
  - market_sequence: (92, 201)       # Same for all tickers
  - ticker_data: {'AAPL': DataFrame, ...}
  - sequence_dates: [92 dates]

For each ticker, __getitem__ returns:
  - market_seq: (92, 201)           # Shared, already standardized
  - stock_feat: (164,)              # Features at anchor date (raw)
  - targets: (30,)                  # Last 30 days of target_ret_1d
  - mask: (30,)                     # 1.0 where data exists, 0.0 where missing

collate_masked_batch() then:
  - Stacks into batches: (B, 92, 201), (B, 164), (B, 30), (B, 30)
  - Standardizes stock features PER-BATCH (zero mean, unit var)

4. KEY OPTIMIZATIONS
================================================================================

| Optimization             | What It Does                              | Speedup   |
|--------------------------|-------------------------------------------|-----------|
| Parquet Rotation         | Only read from 4 parquets instead of 21   | ~10x      |
| Fixed Dates per Epoch    | Load market data once per epoch           | Memory    |
| Predicate Pushdown       | Read only matching rows from parquet      | ~50x      |
| Column Pruning           | Only read needed columns                  | ~2x       |
| OS Page Cache            | Same 4 files cached in RAM for 10 steps   | ~2.5x     |
| Per-Batch Standardization| No pre-fitted scalers needed              | No leakage|


TIMING COMPARISON
-----------------
| Approach                    | Time per Step | Notes                    |
|-----------------------------|---------------|--------------------------|
| OLD (21 files/step)         | ~4,300ms      | Random tickers hit many  |
| NEW (4 files/step)          | ~435ms        | Limited parquet set      |
| NEW + OS Cache (steps 2-10) | ~370ms        | Files cached in RAM      |

6. MODEL ARCHITECTURE SUMMARY
================================================================================

The model follows the conditional factor model framework:

    r̂_{i,t+H} = b_{i,t}^T × λ_t

Where:
  - b_{i,t} = f(x_{i,t})  : Stock exposures from stock features
  - λ_t = g(m_t)          : Factor premia from market state

Components:
  - StockExposureModel: MLP that processes (B, 164) → (B, N_FACTORS)
  - FactorPremiaHead: Processes market sequence → time-varying premia
  - LiquidPremia: Combines both to predict returns
